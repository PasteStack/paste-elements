# Contributing

Thank you for your interest in contributing to **PasteStack Elements**.

This project is part of **Tomshley LLC's OSS and IP strategy** and is part of PasteStack,
which augments the tools a consumer already uses rather than taking over its application
model. It is intentionally opinionated.

## Philosophy

- One concern per module: behaviour and styling shipped together
- Progressive enhancement: the markup is usable before, and without, JavaScript
- No copies, no layout ownership, no dependency on a server-side renderer

Changes that increase complexity, size, or scope without strong justification are unlikely
to be accepted.

## What Contributions Are Welcome

- Bug fixes, especially accessibility and fallback behaviour
- Security improvements
- New modules that follow the enhancement contract and carry checks
- Documentation improvements

## What Is Out of Scope

- Modules that require a specific server framework
- Behaviour that only works with JavaScript enabled
- Changes that contradict the project's architecture or philosophy
- Large refactors without prior discussion

## Process

1. Open an issue describing the change
2. Fork the repository
3. Create a focused merge request
4. Keep commits clean and scoped

Tomshley LLC reserves final decision-making authority on all contributions.
