paste-elements examples

  • reading — scrollscrub publishes progress, CSS owns the bar
  • sequence-hero — imagesequence + scrollscrub + resolution: intro then reversed scroll range, and a windowed traverse
  • avatars — progressiveresolution on standalone images with a declared CSS cap
  • heroscroll — parallax background position and image fade on a hero
  • stickynav — a sub-navigation stuck through the paste-fixed-subnav body class

Each page is a plain document: the authored markup already contains what it needs to be readable, and every script above is an independent declaration. Serve with PASTE_CORE_JS=/path/to/paste/src/js node tests/serve-examples.cjs and open http://127.0.0.1:8087/examples/.
